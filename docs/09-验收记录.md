## 4. 质量验收

| 编号   | 检查项   | 通过标准                             | 结果   | 说明                                        |
| ---- | ----- | -------------------------------- | ---- | ----------------------------------------- |
| Q-01 | 分层规范  | Controller 不写业务，Service 不直接拼 SQL | 通过   | Controller 仅参数绑定与权限声明                     |
| Q-02 | 统一响应  | 所有接口统一结构，错误码有文档                  | 通过   | `Result`、`ErrorCode`、`02-接口文档.md`         |
| Q-03 | 异常处理  | 业务异常与系统异常分离                      | 通过   | `GlobalExceptionHandler`                  |
| Q-04 | 参数校验  | 入参有校验注解，非法参数提示明确                 | 通过   | Jakarta Validation + 业务校验                 |
| Q-05 | 事务    | 多表写操作有事务控制                       | 通过   | `@Transactional` 覆盖主流程                    |
| Q-06 | 分页    | 列表接口分页，限制最大页大小                   | 通过   | `size ≤ 100`                              |
| Q-07 | 安全    | 密码加密、接口鉴权、防越权、参数化 SQL            | 通过   | BCrypt、`@PreAuthorize`、`DataScopeService` |
| Q-08 | 代码规范  | 命名统一、无敏感信息硬编码                    | 部分通过 | JWT 默认密钥与演示密码在配置/种子数据中，已在文档提示替换           |
| Q-09 | 自动化测试 | 核心 Service 至少 8–10 个用例通过         | 通过   | 33 例全绿                                    |
| Q-10 | 日志    | 关键路径有日志，异常有堆栈                    | 部分通过 | 全局异常已记录；业务 info 日志偏少                      |
