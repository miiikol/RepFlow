## 1. 通用约定

### 1.1 基础信息

- Base URL：`http://localhost:8080`
- 接口前缀：`/api`
- 编码：UTF-8
- 时间格式：`yyyy-MM-dd HH:mm:ss`
- 日期格式：`yyyy-MM-dd`
- 字段命名：小驼峰

### 1.2 认证

除登录、Swagger、静态资源外，所有接口要求请求头：

```
Authorization: Bearer <JWT>
```

Token 有效期 2 小时。未登录或过期返回 HTTP 401 与业务码 `10001`。

### 1.3 统一响应

```json
{
  "code": 0,
  "message": "success",
  "data": {},
  "timestamp": "2026-11-11T18:00:00"
}
```

分页响应：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "total": 10,
    "page": 1,
    "size": 20,
    "records": []
  }
}
```

页码从 1 开始，`size` 最大 100。

### 1.4 错误码

| 业务码   | 含义               | HTTP |
| ----- | ---------------- | ---- |
| 0     | 成功               | 200  |
| 10001 | 未登录或登录已过期        | 401  |
| 10002 | 账号已锁定            | 401  |
| 10003 | 用户名或密码错误         | 401  |
| 10004 | 账号已停用            | 401  |
| 20001 | 无操作权限            | 403  |
| 20002 | 数据越权             | 403  |
| 30001 | 参数校验失败           | 400  |
| 40001 | 业务处理失败           | 400  |
| 40002 | 非法状态流转 / 前置条件不满足 | 400  |
| 40004 | 数据不存在            | 404  |
| 40005 | 数据已归档，只读         | 400  |
| 40007 | 并发冲突，请刷新重试       | 409  |
| 50000 | 系统繁忙             | 500  |

### 1.5 快速示例

```bash
curl -s -X POST http://localhost:8080/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"ra","password":"Reqflow@123"}'
```

响应中的 `data.token` 即 JWT，后续请求放入 `Authorization` 头。

## 2. 接口清单

共 50 个操作（以 OpenAPI 统计为准），按模块分组。

### 2.1 认证 Auth

| 方法   | 路径                   | 权限   | 说明                      |
| ---- | -------------------- | ---- | ----------------------- |
| POST | `/api/auth/login`    | 匿名   | 登录，返回 Token、角色、权限点与数据范围 |
| POST | `/api/auth/logout`   | 登录用户 | 前端清除 Token（服务端无黑名单）     |
| GET  | `/api/auth/me`       | 登录用户 | 当前用户信息                  |
| PUT  | `/api/auth/password` | 登录用户 | 修改本人密码，校验原密码            |

登录请求：

```json
{ "username": "ra", "password": "Reqflow@123" }
```

登录响应 `data` 关键字段：`token`、`tokenType`、`expiresIn`、`user`（含 `roles`、`permissions`、`dataScope`、`mustChangePwd`）。

### 2.2 需求 Requirement

| 方法     | 路径                                            | 权限                   | 说明                              |
| ------ | --------------------------------------------- | -------------------- | ------------------------------- |
| GET    | `/api/requirements`                           | `requirement:view`   | 分页列表，七类筛选                       |
| GET    | `/api/requirements/export`                    | `requirement:view`   | 按筛选条件导出 Excel                   |
| GET    | `/api/requirements/{id}`                      | `requirement:view`   | 详情聚合（评审/变更/任务/交付物/验收/版本/附件/时间线） |
| POST   | `/api/requirements`                           | `requirement:create` | 新建需求（草稿）                        |
| PUT    | `/api/requirements/{id}`                      | `requirement:edit`   | 编辑需求                            |
| DELETE | `/api/requirements/{id}`                      | `requirement:delete` | 删除草稿（逻辑删除）                      |
| POST   | `/api/requirements/{id}/action`               | `requirement:action` | 执行状态动作                          |
| GET    | `/api/requirements/{id}/versions`             | `requirement:view`   | 版本历史                            |
| POST   | `/api/requirements/{id}/attachments`          | `requirement:edit`   | 上传附件（multipart）                 |
| GET    | `/api/requirements/attachments/{id}/download` | `requirement:view`   | 下载附件（校验数据权限）                    |
| DELETE | `/api/requirements/attachments/{id}`          | `requirement:edit`   | 删除附件（上传人或 ADMIN）                |

列表查询参数：

| 参数          | 类型      | 说明           |
| ----------- | ------- | ------------ |
| page / size | long    | 页码、页大小（≤100） |
| keyword     | string  | 标题或需求编号模糊匹配  |
| status      | string  | 支持逗号分隔多状态    |
| deptId      | long    | 业务部门         |
| priority    | string  | P0–P3        |
| type        | string  | 需求类型         |
| proposerId  | long    | 提出人          |
| mine        | boolean | 只看我参与的需求     |

状态动作请求：

```json
{ "action": "SUBMIT", "comment": "补充验收标准", "projectId": null, "milestoneId": null, "planDate": null }
```

- `action` 枚举：`SUBMIT`、`ACCEPT`、`RESUBMIT`、`SCHEDULE`、`START_DEV`、`SUBMIT_TEST`、`ARCHIVE`、`HOLD`、`RESUME`、`CANCEL`；
- `SUBMIT_REVIEW`、`REVIEW_PASS`、`REVIEW_REJECT`、`SUBMIT_ACCEPTANCE`、`ACCEPT_PASS`、`ACCEPT_REJECT` 由评审单/验收单驱动，不能通过该接口直接调用；
- 排期时 `projectId`、`milestoneId` 必填；
- 冲突返回 `409 / 40007`。

### 2.3 评审 Review

| 方法   | 路径                             | 权限               | 说明             |
| ---- | ------------------------------ | ---------------- | -------------- |
| GET  | `/api/reviews`                 | `review:view`    | 评审单分页，按需求可见性过滤 |
| GET  | `/api/reviews/{id}`            | `review:view`    | 评审详情与意见        |
| POST | `/api/reviews`                 | `review:create`  | 发起评审           |
| POST | `/api/reviews/{id}/opinions`   | `review:opinion` | 提交评审意见         |
| POST | `/api/reviews/{id}/conclusion` | `review:decide`  | 提交评审结论         |

发起评审请求：

```json
{
  "requirementId": 1,
  "type": "REQUIREMENT",
  "method": "SINGLE",
  "hostId": 3,
  "reviewerIds": [2, 4, 6],
  "deadline": "2026-11-15 18:00:00",
  "comment": "请重点评审验收标准"
}
```

结论请求：

```json
{ "pass": true, "comment": "同意进入排期" }
```

### 2.5 计划与任务 Project / Task

| 方法   | 路径                         | 权限               | 说明         |
| ---- | -------------------------- | ---------------- | ---------- |
| GET  | `/api/projects`            | `project:view`   | 项目列表（含里程碑） |
| POST | `/api/projects`            | `project:manage` | 创建项目       |
| POST | `/api/projects/milestones` | `project:manage` | 创建里程碑      |
| GET  | `/api/tasks`               | `task:view`      | 任务分页       |
| POST | `/api/tasks`               | `task:manage`    | 创建任务       |

任务状态请求：

```json
{ "status": "DONE", "finishNote": "完成开发并自测", "actualHours": 6.5 }
```

- 完成必须填 `finishNote`；
- 阻塞必须填 `blockReason`；
- 非法流转返回 `40002`。

## 3. 契约导出与维护

### 3.1 重新导出

后端启动后执行：

```bash
curl -s http://localhost:8080/v3/api-docs -o docs/api/openapi.json
```

### 3.2 查看方式

1. **在线 Swagger UI**：`http://localhost:8080/swagger-ui.html`；
2. **离线 HTML**：

```bash
cd docs/api
python -m http.server 8000
# 浏览器访问 http://localhost:8000/
```

3. **机器可读**：直接使用 `docs/api/openapi.json`，可导入 Postman、Apifox、YApi。

### 3.3 维护约定

- 新增接口必须同步权限点注解，否则默认拒绝或越权；
- 状态动作类接口只接收动作编码，禁止暴露目标状态字段；
- 错误码复用 `ErrorCode` 枚举，不新增无文档的魔法数字；
- 接口变更后重新导出 `openapi.json`，并在提交信息中注明契约变更。
